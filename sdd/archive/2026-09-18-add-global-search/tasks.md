# add-global-search 任務清單

- [x] 1. textio.go 抽出文字解碼；search.go 資料夾搜尋（略過規則、編碼、選項、筆數上限）
- [x] 2. search.js：搜尋面板（輸入框、三個選項、結果分組、收合、標示符合處）
- [x] 3. 合併開啟分頁（以目前內容為準）與資料夾結果；點結果開檔、跳行並選取
- [x] 4. Ctrl+Shift+F、regex 錯誤提示、中英文字串
- [x] 5. 建置並驗收

## 驗收條件

- 情境：開啟資料夾後搜尋「倉儲」，列出資料夾內所有含該字的文字檔與行號，並顯示總筆數
- 情境：分頁中有未存檔的修改，搜尋結果反映目前的內容
- 情境：勾選「區分大小寫」「全字比對」「規則運算式」後結果對應改變
- 情境：輸入錯誤的規則運算式（例如 `(`）顯示錯誤訊息，不當掉
- 情境：點某一筆結果，開啟該檔案、游標跳到該行並選取符合的文字
- 情境：`node_modules`、`.git` 內的檔案與圖片等二進位檔不出現在結果中
- 情境：按 Ctrl+Shift+F 開啟搜尋面板並聚焦輸入框
