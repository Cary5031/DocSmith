# add-ebook-reader 任務清單

- [x] 1. 引入 foliate-js（移除未使用與 PDF 部分）；state.go 小型資料存放
- [x] 2. viewers/ebook.js：開啟電子書、翻頁排版（單 / 雙頁）、DRM 偵測、外部連結
- [x] 3. 閱讀偏好：字級、行距、字型、主題（白 / 米 / 深）
- [x] 4. 導覽：目錄側欄、上下頁與鍵盤、進度列、記住閱讀位置
- [x] 5. 書籤與全書搜尋
- [x] 6. 註冊閱讀器、狀態列、中英文字串
- [x] 7. 建置並驗收（EPUB 橫排 / 直排、MOBI、CBZ）

## 驗收條件

- 情境：開啟 EPUB，以翻頁方式顯示；視窗寬時左右兩頁並排
- 情境：按 → 或「下一頁」翻到下一頁，底部進度百分比增加
- 情境：開啟目錄側欄點某章節，跳到該章節，狀態列顯示章節名稱
- 情境：字級放大、切換米色主題後，內文立即改變；重開另一本書仍套用
- 情境：加入書籤後關閉再開啟，書籤還在；點書籤跳回該位置
- 情境：搜尋關鍵字列出結果與前後文，點結果跳轉
- 情境：關閉後重新開啟同一本書，回到上次閱讀的位置
- 情境：直排的中文 EPUB 以直排、由右至左翻頁顯示
- 情境：MOBI / AZW3 / CBZ 可以開啟
- 情境：有 DRM 的書顯示無法開啟的訊息
