# add-ebook-reader（新功能）

## 為什麼做

公司內有電子書形式的規範、教材與手冊。希望 DocSmith 能當作實用的電子書閱讀器，而且排版要符合電子書的閱讀習慣（翻頁、目錄、字級），而不是當成一般文件捲動。

## 要改什麼

- 支援 **EPUB、MOBI、AZW3、FB2、CBZ**（使用 foliate-js，完全離線）
- **電子書排版**：
  - 翻頁式閱讀（非捲動）；視窗夠寬時自動雙頁並排，窄時單頁
  - 遵循書本本身的樣式、直排 / 橫排、由右至左（例如中文直排書、日文書）
  - 固定版面（漫畫、繪本、固定版型 EPUB）以整頁顯示
  - 可調整：字級、行距、字型（明體 / 黑體）、主題（白色 / 米色 / 深色）；設定套用到所有書
- **導覽**：
  - 目錄側欄（多層），標示目前所在章節
  - 上一頁 / 下一頁按鈕、鍵盤（← →、PageUp / PageDown、空白鍵）、滑鼠滾輪
  - 底部進度列：可拖曳跳到任意位置，顯示目前章節與百分比
- **書籤**：加入 / 移除目前位置的書籤，側欄列出書籤可點選跳轉
- **全書搜尋**：列出所有結果（含前後文），點選跳轉並標示
- **記住閱讀位置**：重新開啟同一本書時回到上次讀到的地方
- 書中的外部連結用預設瀏覽器開啟
- 有 DRM 保護的書顯示「此電子書有 DRM 保護，無法開啟」
- 狀態列顯示目前章節與閱讀進度

## 影響範圍

- `frontend/vendor/foliate-js/`（第三方，已移除不需要的部分）
- `frontend/src/viewers/ebook.js`（新增：電子書閱讀器）
- `frontend/src/main.js`（註冊閱讀器）
- `frontend/src/style.css`、`frontend/src/i18n.js`
- `state.go`（新增：閱讀位置、書籤、閱讀偏好等小型資料的存放，`%APPDATA%\DocSmith\state.json`）
