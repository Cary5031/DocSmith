## 驗收條件

- 情境：點活動列「檔案總管」→「開啟資料夾」選擇資料夾後，顯示樹狀清單，資料夾在前
- 情境：展開子資料夾看到內容；點 .md 開成 Markdown 分頁、點 .pdf 開 PDF 閱讀器、點 .epub 開電子書
- 情境：切換分頁時，檔案總管標示對應的檔案
- 情境：重開程式後，檔案總管仍是上次的資料夾與展開狀態
- 情境：拖曳側欄邊界可調整寬度，重開後保留
- 情境：Markdown 分頁的大綱列出各層標題，點標題編輯區跳到該行；移動游標時大綱標示目前章節
- 情境：Python / JavaScript 檔案的大綱列出函式與類別
- 情境：PDF 大綱顯示書籤、電子書大綱顯示目錄，點選可跳轉
- 情境：編輯 Markdown 新增標題，大綱自動更新
