# add-pdf-viewer 任務清單

- [x] 1. viewers/pdf.js：以 pdf.js PDFViewer 顯示 PDF（分段讀取、文字可選取、連結處理、不執行腳本）
- [x] 2. 閱讀器工具列：頁碼 / 上下頁、縮放、縮圖側欄
- [x] 3. 搜尋（即時、上一個 / 下一個、結果數）
- [x] 4. main.js：註冊閱讀器、狀態列、快捷鍵（Ctrl+F、Ctrl+±、Ctrl+0）、中英文字串
- [x] 5. 建置並驗收

## 驗收條件

- 情境：開啟 PDF，顯示原始版面（含圖片、表格），狀態列顯示「第 1 / N 頁」
- 情境：輸入頁碼或按上下頁可跳頁；點縮圖跳到該頁
- 情境：縮放選單切換「符合頁寬 / 整頁 / 150%」後頁面大小對應改變；Ctrl+加號放大
- 情境：搜尋關鍵字，所有結果高亮、顯示「1 / 3」，按下一個會捲動到下一個結果
- 情境：可用滑鼠選取文字並複製
- 情境：按「轉為 Markdown」產生 Markdown 新分頁
- 情境：開兩個 PDF 分頁互相切換，各自的頁碼與縮放保留
- 情境：關閉 PDF 分頁後釋放資源（不殘留閱讀器元件）
