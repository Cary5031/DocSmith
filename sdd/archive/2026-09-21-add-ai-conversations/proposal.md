# add-ai-conversations（新功能）

> 這是兩份提案中的第一份：**多組對話與存放方式**。
> Token 用量長條與上限設定另外寫在 `sdd/add-ai-token-usage/`，等這份做完再做。

## 為什麼做

目前 AI 面板只有**一組**對話，而且會一直累積：

- 換一個主題時沒有「開新對話」可按，只能「清除對話」，舊的內容就永遠消失（先前就發生過清掉之後救不回來）
- 每次送出都會帶最近 12 則歷史，對話越長、每次請求的 token 越多，錢和時間浪費在重複的內容上
- 對話只存在 `state.json` 裡，沒有備份，也沒辦法拿出來給別人看

## 要改什麼

### 1. 多組對話 + 對話紀錄

- 面板標題列新增兩個按鈕：**新對話**、**對話紀錄**
- **新對話**：把目前這組存起來，訊息清空
- **對話紀錄**：在面板內展開清單，每列顯示「標題（第一則問題的前 20 字）、最後更新時間、則數」
  - 點一下切換過去，訊息一起回來
  - 每列有刪除、匯出按鈕
- 「清除對話」改成只清空目前這組的訊息；要刪掉整組請用對話紀錄裡的刪除

### 2. 對話存放方式（壓縮 ＋ 本機加密 ＋ 明文備援）

- **主要位置**：有開啟資料夾時放在該資料夾的 `.DocSmith\chats\`（每個專案有自己的對話紀錄）；沒開資料夾時放 `%APPDATA%\DocSmith\chats\`
- **格式**：一組對話一個檔（`<id>.dsc`），內容先 gzip 壓縮、再用 **Windows DPAPI**（目前 Windows 帳號）加密；複製到別台電腦或別的帳號都解不開
- **明文備援**：同一份內容同時寫一份未加密的 `%APPDATA%\DocSmith\chats-backup\<id>.json`
  - 加密檔讀不到時（換帳號、重灌、檔案損毀）自動改讀備援，資料不會不見
  - **代價**：拿到備援檔的人就讀得到內容，所以「只有這台能解」實際上只保護專案目錄那一份
- `.DocSmith\` 建立時會自動寫入一個內容為 `*` 的 `.gitignore`，避免被 git 收進專案
- 每個資料夾保留最近 **100 組**（每組最多 60 則訊息），超過自動刪最舊的
- 升級時，原本存在 `state.json` 的單一對話會自動搬成第一組，內容不會不見

### 3. 匯出與備份（使用者主動操作，一律明文）

- **匯出單一對話**：對話紀錄每列的匯出按鈕 → 存成 **Markdown**（標題、時間、模型，接著一問一答；程式碼區塊保留）
- **備份整份紀錄**：一個按鈕把目前資料夾的所有對話存成**一個 JSON 檔**
- **從備份還原**：選一個備份 JSON 匯入，同 id 覆蓋、不同 id 新增（沒有還原的備份等於沒有備份，所以一起做）

## 影響範圍

- `chatstore.go`（新增：對話檔讀寫、gzip、DPAPI、明文備援、100 組上限、`.gitignore`）
- `frontend/src/ai/panel.js`（多組對話的資料與 UI）
- `frontend/src/ai/history.js`（新增：對話紀錄清單、匯出、備份、還原）
- `frontend/src/i18n.js`、`frontend/src/style.css`

## 不做什麼

- 不做跨裝置同步、不上雲（全部留在本機）
- 不自動幫使用者開新對話、也不自動截斷歷史
