# add-auto-update 任務清單

- [x] 1. updater.go：內嵌 version.json、取得目前版本、檢查 GitHub 最新版本（逾時、Proxy、版本比較）
- [x] 2. updater.go：下載（進度事件）、驗證（大小 / MZ / SHA-256）
- [x] 3. updater.go + main.go：替換執行中的 exe 並重新啟動（一般 / 需要系統管理員權限兩種路徑）、新版啟動時等待舊版結束並清除 .old
- [x] 4. 前端：右下角更新卡片（說明、進度、錯誤重試）、未存檔確認、定期檢查、更新完成提示；中英文字串
- [x] 5. publish.ps1 寫入 SHA-256；建置並驗收（舊版本號測試版 → 實際從 GitHub 更新）

## 驗收條件

- 情境：目前版本比 GitHub 舊時，啟動後右下角出現「有新版本」卡片與更新說明
- 情境：目前已是最新版本時，不出現卡片
- 情境：網路離線（或連不到 GitHub）時，不出現任何提示或錯誤
- 情境：按「稍後」卡片關閉，本次執行不再出現（6 小時後的定期檢查才會再提示）
- 情境：按「立即更新」時有未存檔分頁，會先詢問；按取消則不更新
- 情境：更新時卡片顯示下載進度；完成後程式自動重新啟動成新版，舊檔 .old 被清除，並提示已更新
- 情境：下載的檔案 SHA-256 不符時，不替換並顯示錯誤，原程式照常使用
