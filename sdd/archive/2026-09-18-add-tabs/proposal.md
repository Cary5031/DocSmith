# add-tabs（新功能）

## 為什麼做

同時參考、編輯多份文件時，目前一次只能開一份，要反覆開關檔案。

## 要改什麼

- 工具列下方新增分頁列：顯示每份文件的檔名，未存檔的分頁顯示「●」，滑鼠停留顯示完整路徑
- 新增（Ctrl+N）開新分頁；開啟檔案（Ctrl+O，可多選）、拖放檔案（可多個）、命令列參數（可多個）都各自開成分頁
- 開啟已經開著的檔案時，直接切換到該分頁，不重複開
- 目前分頁是空白且未修改的「未命名」時，開檔直接取代它
- 關閉分頁：分頁上的 ×、滑鼠中鍵、Ctrl+W；有未存變更時詢問；關掉最後一個分頁時自動留一個空白分頁
- 切換分頁：點選、Ctrl+Tab / Ctrl+Shift+Tab
- 每個分頁各自保留內容、游標、復原紀錄、捲動位置
- 關閉視窗時，逐一詢問每個有未存變更的分頁；任何一個按取消就不關閉
- 預覽的相對路徑圖片以「目前分頁」的檔案位置為準

## 影響範圍

- `frontend/index.html`（分頁列容器）
- `frontend/src/main.js`（分頁狀態管理，改寫檔案操作與未存檔流程）
- `frontend/src/editor.js`（每個分頁建立獨立 EditorState）
- `frontend/src/style.css`、`frontend/src/i18n.js`
- `app.go`（開啟對話框可多選、啟動參數可多個）
