# add-session-restore 任務清單

- [x] 1. backup.go：寫入、列出、刪除、清除備份
- [x] 2. main.js：分頁開啟 / 關閉事件、關閉程式前的處理、開啟還原內容的介面
- [x] 3. session.js：記錄開啟的分頁與作用中分頁；啟動時還原（略過不存在的檔案）
- [x] 4. session.js：未存檔內容定時備份、存檔 / 關閉 / 正常結束時刪除備份
- [x] 5. session.js：啟動時偵測上次的備份並詢問還原或捨棄；中英文字串
- [x] 6. 建置並驗收（含強制結束程式的情境）

## 驗收條件

- 情境：開著 A.md、B.pdf、C.epub 並停在 B，正常關閉後重開，三個分頁都在且停在 B
- 情境：其中一個檔案被刪除後重開，其餘分頁正常還原，不出現錯誤
- 情境：修改 A.md 不存檔，等 3 秒後強制結束程式（工作管理員），重開時詢問還原；按還原後 A.md 顯示修改後內容並標示未存檔
- 情境：新增未命名文件打字後強制結束，重開可還原該內容
- 情境：按捨棄後備份被刪除，下次啟動不再詢問
- 情境：修改後存檔，備份資料夾中沒有該分頁的備份
- 情境：正常關閉（選不儲存）後重開，不詢問還原
