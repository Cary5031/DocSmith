# add-session-restore（新功能）

## 為什麼做

每次開程式都要重新開啟上次的文件很麻煩；而程式當機、電腦突然斷電或被強制關閉時，尚未存檔的內容會全部遺失。

## 要改什麼

- **工作階段還原**：重新開啟程式時，自動開回上次開著的分頁（含 PDF、電子書），並切到上次作用中的分頁
  - 已被刪除或搬走的檔案略過
  - 以命令列 / 雙擊開啟檔案時，先還原上次的分頁，再開啟指定的檔案
- **自動備份未存檔內容**：有未存檔修改的分頁，停止輸入約 3 秒後把內容備份到 `%APPDATA%\DocSmith\backup\`
  - 存檔、復原到未修改狀態、關閉分頁（選不儲存）時刪除該分頁的備份
  - 正常關閉程式時清除所有備份
- **當機復原**：啟動時若發現上次沒有正常關閉留下的備份，詢問「要還原 N 份未儲存的內容嗎？」
  - 還原：開成分頁並標示未存檔（原本有檔案的，以備份內容覆蓋在該檔案的分頁上，存檔即寫回原位置）
  - 捨棄：刪除備份

## 影響範圍

- `backup.go`（新增：寫入 / 列出 / 刪除備份）
- `frontend/src/session.js`（新增：工作階段記錄與還原、備份排程、當機復原）
- `frontend/src/main.js`（分頁開關事件、還原分頁的介面、關閉前的處理）
- `frontend/src/i18n.js`
