## 驗收條件

- 情境：在輸入框打「請幫我產生一份符合現代化 AI 的指引提示詞」並送出，回覆結束後，該則訊息底部會出現「插入游標處 / 取代選取範圍 / 開成新分頁 / 複製」，按「開成新分頁」就把整份內容開成一個新的 Markdown 分頁。
- 情境：當模型把整份文件包在 ``` 圍籬裡回覆，按「插入游標處」寫進文件的是文件本身，開頭結尾不會多出 ``` 那幾行。
- 情境：當目前作用中的分頁是 PDF 或電子書，「插入游標處」「取代選取範圍」是停用狀態，滑鼠移上去會說明原因，「開成新分頁」與「複製」仍可用。
- 情境：把模式切到「改寫文件」再送出問題，回覆結束後出現「套用到文件」，按下去會先跳出差異比較視窗，確認後才改動文件，且可用 Ctrl+Z 復原。
- 情境：把模式切到「新文件」再送出問題，回覆結束後出現「開成新分頁」，按下去開出未存檔的 Markdown 分頁。
- 情境：選了「改寫文件」後關掉面板再打開，模式仍然停在「改寫文件」。
- 情境：AI 回覆失敗（顯示紅色錯誤訊息）時，該則訊息底下沒有任何動作列。
- 情境：上方「摘要」「潤稿」等七顆常用動作按下去的行為，跟改動前完全一樣。
