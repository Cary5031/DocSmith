# add-ai-settings 任務清單

- [x] 1. ai.go：設定結構與存檔（ai.json）、DPAPI 加解密金鑰與表頭值、前端只拿到遮罩
- [x] 2. ai.go：公司政策（DisableAI、AllowedAIProviders、CustomBaseURL）
- [x] 3. ai.go：取得模型清單、測試連線（OpenAI 相容 API；自訂表頭；清楚的錯誤訊息；Proxy）
- [x] 4. settings.js：AI 設定對話框（供應商、網址、金鑰、表頭、模型清單、測試連線、儲存）
- [x] 5. 第一次使用的資料傳送提醒；工具列設定按鈕；中英文字串
- [x] 6. 建置並驗收（本機模擬的 OpenAI 相容服務＋真實服務的錯誤處理）

## 驗收條件

- 情境：選「自訂模型」填入網址、金鑰與自訂表頭，按「取得模型清單」列出服務上的模型
- 情境：按「測試連線」顯示成功與延遲；服務端確實收到自訂表頭與金鑰
- 情境：金鑰錯誤顯示「金鑰無效或沒有權限」；網址錯誤 / 無法連線顯示對應訊息
- 情境：儲存後重開設定，金鑰只顯示遮罩；ai.json 內看不到金鑰明文
- 情境：OpenAI、Gemini、DeepSeek 選項帶入正確的預設網址；各供應商設定分開保存
- 情境：登錄檔設定 AllowedAIProviders=custom 時，只能選自訂模型；設定 CustomBaseURL 時網址不能修改
- 情境：第一次使用時出現資料傳送提醒，按「我了解」後不再出現
