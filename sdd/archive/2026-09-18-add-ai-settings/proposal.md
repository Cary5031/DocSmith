# add-ai-settings（新功能）

## 為什麼做

AI 對話功能需要先設定要使用的模型服務。公司內可能使用不同供應商，也可能架設內部模型；同時 API 金鑰屬於機密，公司也需要能控管文件內容會被送到哪裡。

## 要改什麼

- 工具列新增「設定」按鈕，開啟「AI 設定」對話框：
  - **供應商**：OpenAI、Gemini、DeepSeek、自訂模型（任何 OpenAI 相容的服務，例如公司內部模型、Ollama、Azure OpenAI）
  - **服務網址（Base URL）**：各供應商帶入預設值，可修改（例如經由公司代理）
  - **API 金鑰**：密碼欄位；已儲存時只顯示遮罩（如 `sk-…abcd`），可更換或清除
  - **自訂表頭**（自訂模型）：可新增 / 刪除多組「名稱：值」，每次呼叫都會帶上（例如 `api-key`、`X-Tenant`）
  - **模型**：可直接輸入，或按「取得模型清單」自動列出該服務可用的模型供選擇
  - **測試連線**：實際呼叫服務，顯示成功（延遲、可用模型數）或錯誤原因（金鑰錯誤、網址錯誤、無法連線等）
- 每個供應商的設定分開保存，切換供應商不會遺失
- **金鑰安全**：API 金鑰與自訂表頭的值以 Windows DPAPI 加密後存放（只有目前的 Windows 帳號能解密），前端網頁拿不到明文；所有 AI 呼叫都由程式後端發出
- **公司資料政策**：
  - 第一次使用 AI 時顯示提醒：「開啟的文件內容會傳送到所選的 AI 服務」，需按「我了解」才能使用
  - 系統管理員可用群組原則（登錄檔 `HKLM\SOFTWARE\Policies\DocSmith`）：
    - `DisableAI`（DWORD=1）：完全停用 AI 功能
    - `AllowedAIProviders`（字串，例如 `custom` 或 `custom,openai`）：只允許指定的供應商
    - `CustomBaseURL`（字串）：固定自訂模型的服務網址（使用者不能修改）
  - 設定畫面會顯示目前受公司政策限制的項目

## 影響範圍

- `ai.go`（新增：設定存取、DPAPI 加解密、公司政策、取得模型清單、測試連線）
- `frontend/src/ai/settings.js`（新增：AI 設定對話框）
- `frontend/src/main.js`（工具列設定按鈕）
- `frontend/src/style.css`、`frontend/src/i18n.js`
