# add-export 任務清單

- [x] 1. export.go：匯出存檔對話框、尋找 Edge 並以無頭模式列印 PDF、寫入二進位檔、以預設程式開啟
- [x] 2. export.js：在隱藏容器重新繪製文件（等待圖表完成），圖片轉 data URI，收集 CSS 並內嵌字型，組出獨立 HTML
- [x] 3. export.js：DOM 轉 docx（標題、段落與行內格式、連結、清單、引用、程式碼、表格、分隔線、圖片）
- [x] 4. export.js：Mermaid 圖表與數學公式轉 PNG 嵌入 docx
- [x] 5. main.js：工具列匯出按鈕、匯出流程、完成後詢問開啟、錯誤處理；中英文字串
- [x] 6. 建置並以測試版驗收（含檢查 PDF 文字與 docx 內容）

## 驗收條件

- 情境：按「匯出 PDF」選擇位置後，產生 PDF；PDF 內含可搜尋的中文字，表格、程式碼、圖片、Mermaid 圖表、數學公式都有顯示
- 情境：按「匯出 Word」後產生 .docx；用 Word 開啟可看到標題樣式、清單、表格、程式碼區塊、連結、圖片
- 情境：Word 檔中的 Mermaid 圖表與數學公式以圖片呈現
- 情境：匯出完成後詢問「要開啟嗎？」，選是就用系統預設程式開啟
- 情境：匯出目標檔案被其他程式鎖定時，顯示錯誤訊息，程式不當掉
- 情境：未命名文件也能匯出，預設檔名為「未命名.pdf / 未命名.docx」
- 情境：匯出過程不需要網路
