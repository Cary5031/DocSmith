# markdown-editor 任務清單

- [x] 1. 安裝 wails CLI，建立 Wails 專案骨架（Go + Vite 前端），啟動後能顯示主視窗
- [x] 2. 以 npm 安裝前端函式庫（CodeMirror 6、markdown-it + task-lists、highlight.js、DOMPurify），由 Vite 打包內嵌，不引用任何外部網址
- [x] 3. 主畫面版面：上方工具列、左編輯區、右預覽區；即時預覽 + 分割模式同步捲動
- [x] 4. 主程式↔前端橋接：新增 / 開啟 / 儲存 / 另存新檔（原生對話框、UTF-8）、拖放開檔、命令列參數開檔
- [x] 5. 未存檔保護：標題列顯示檔名與 `*`，關閉視窗 / 新增 / 開啟前詢問是否儲存
- [x] 6. 預覽正確性：相對路徑圖片可顯示、外部連結用預設瀏覽器開啟、HTML 經 DOMPurify 過濾
- [x] 7. 格式工具列按鈕 + 快捷鍵（粗體、斜體、刪除線、標題、清單、任務清單、引用、程式碼、連結、圖片、表格、分隔線）
- [x] 8. 檢視模式切換：只編輯 / 分割 / 只預覽
- [x] 9. 介面語言切換 English / 繁體中文（含工具列提示、對話框訊息），記住設定；首次依系統語言
- [x] 10. 撰寫 `publish.ps1`（`wails build`）產生單一 exe，實際執行驗收並補 `README.md`

## 驗收條件

- 情境：在沒裝任何額外軟體的公司 Windows 10/11 電腦上，把 `MarkDownBuilder.exe` 複製過去雙擊，就能開啟編輯器（前提：系統已有 WebView2 Runtime，Win10 更新過的都有）
- 情境：拔掉網路線啟動並開檔，編輯與預覽都正常，沒有缺圖示或排版跑掉
- 情境：開啟一份含表格、任務清單、程式碼區塊、中文內容的 .md，右邊預覽正確排版，程式碼有語法上色，中文不是亂碼
- 情境：在左邊打字，右邊預覽在一秒內更新；捲動左邊，右邊跟著捲到對應位置
- 情境：把 .md 檔拖進視窗，就開啟該檔；用「開啟檔案 → 選擇此程式」或 `MarkDownBuilder.exe 文件.md` 也能直接開檔
- 情境：修改內容後標題列出現 `*`；按 Ctrl+S 存檔後 `*` 消失，檔案以 UTF-8 存回原位置
- 情境：有未存變更時按關閉，跳出「儲存 / 不儲存 / 取消」；按取消則視窗不關
- 情境：文件中 `![](images/a.png)` 這類相對路徑圖片在預覽中正常顯示
- 情境：點預覽中的 `https://` 連結，用系統預設瀏覽器開啟，不會在編輯器裡跳頁
- 情境：文件內含 `<script>alert(1)</script>`，預覽不會執行它
- 情境：選取文字後按「粗體」按鈕或 Ctrl+B，文字被 `**` 包起來；按「表格」插入一個 3 欄範本表格
- 情境：切換「只編輯 / 分割 / 只預覽」，版面立即改變
- 情境：切換語言為 English，所有按鈕提示、選單、對話框文字立即變英文；關掉重開後仍是 English
- 情境：執行 `publish.ps1` 後，輸出資料夾裡只需要一個 `MarkDownBuilder.exe` 就能執行
