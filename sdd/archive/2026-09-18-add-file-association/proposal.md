# add-file-association（新功能）

## 為什麼做

希望同事雙擊 .md 檔就直接用 MarkDown Builder 開啟，不用每次手動選「開啟檔案 → 選擇程式」。

## 要改什麼

- **自動註冊**：每次啟動時，將程式註冊到目前使用者（HKCU，不需要系統管理員權限）：
  - .md / .markdown / .mdown / .mkd 的「開啟檔案」清單出現 MarkDown Builder
  - Windows「設定 → 預設應用程式」中可選擇 MarkDown Builder
  - 註冊的程式路徑隨 exe 目前位置更新（exe 搬移後重新開一次即可）
- **設為預設程式**：Windows 10/11 不允許程式自行設定預設，因此：
  - 第一次啟動、且目前不是 .md 預設程式時，詢問「要設為預設嗎？」（設定 / 以後再說 / 不要再問）
  - 選「設定」時開啟 Windows 的「選擇開啟方式」視窗，由使用者勾選「一律使用此應用程式」
  - 狀態列右側顯示「設為預設程式」連結（已是預設時不顯示），隨時可再設定
- **只執行一個程式**：程式已開啟時，雙擊其他 .md（或命令列開檔）會在既有視窗開成新分頁，並把視窗帶到最前面

## 影響範圍

- `assoc.go`（新增：註冊檔案關聯、檢查是否為預設、開啟「選擇開啟方式」視窗）
- `main.go`（啟動時註冊、單一執行個體與第二個執行個體的檔案轉交）
- `app.go`（設定新增「不要再問」欄位）
- `frontend/src/main.js`（首次詢問、狀態列連結、接收其他執行個體轉交的檔案；設定整份保存）
- `frontend/index.html`、`frontend/src/i18n.js`、`frontend/src/style.css`
