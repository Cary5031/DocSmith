# add-ai-chat 任務清單

- [x] 1. aichat.go：以設定的服務串流對話（SSE）、取消、錯誤回報
- [x] 2. 版面：右側 AI 面板（顯示 / 隱藏、可調寬度、狀態記住）、AI 按鈕與 Ctrl+Shift+A
- [x] 3. panel.js：對話顯示（Markdown 渲染、串流逐字）、輸入、停止、清除、對話保存
- [x] 4. panel.js：分頁內容勾選（含 PDF 文字、長度截斷說明）
- [x] 5. panel.js：常用動作（摘要 / 潤稿 / 翻譯 / 加註解 / 修正 / 產生說明文件）
- [x] 6. 回覆的套用：程式碼區塊的插入 / 取代 / 開新分頁 / 複製；整份改寫的差異預覽與套用
- [x] 7. 未設定模型的引導、資料傳送提醒、政策停用；中英文字串
- [x] 8. 建置並以本機模擬服務驗收

## 驗收條件

- 情境：按 AI 按鈕，面板從右側出現；再按一次收起；重開程式維持上次狀態與寬度
- 情境：輸入問題後回覆逐字出現；按「停止」可中斷
- 情境：面板列出所有開啟的分頁，預設勾選目前分頁；勾選兩份文件後提問，服務端收到兩份內容
- 情境：勾選 PDF 分頁時，送出的是 PDF 的文字內容
- 情境：按「摘要」直接送出摘要要求並得到回覆
- 情境：回覆中的程式碼區塊可「插入游標處」「取代選取範圍」「開成新分頁」「複製」，結果正確
- 情境：按「潤稿」後出現「套用到文件」，點選後顯示差異比較，確認才修改，可用 Ctrl+Z 復原
- 情境：「產生說明文件」的結果可開成新的 Markdown 分頁
- 情境：尚未設定模型時，面板引導開啟 AI 設定
- 情境：第一次使用顯示資料傳送提醒，同意後才開始
- 情境：對話內容重開程式後仍在，按「清除」可清空
