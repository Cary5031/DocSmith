## 驗收條件

- 情境：工具開關關閉時送出問題，請求內容與現在完全相同（不含 `tools`），回覆行為不變
- 情境：開關打開、側邊欄開著資料夾，問「這個資料夾裡哪些檔案提到 MCP？」，面板先出現「🔧 搜尋資料夾：MCP」，接著模型根據搜尋結果回答
- 情境：模型連續呼叫多個工具（例如先搜尋、再讀檔），每一次都顯示一行，最後給出一般回覆
- 情境：模型要求讀取 `../../Windows/win.ini` 或 `C:\` 開頭的路徑，工具回報「超出資料夾範圍」，不讀取任何檔案
- 情境：開關打開但沒有開資料夾，請求不帶 `tools`，照一般對話回覆
- 情境：模型連續要求超過 8 輪工具，迴圈停止，面板提示「工具呼叫次數已達上限」
- 情境：工具執行中按「停止」，迴圈立即中斷，不再送出下一輪
- 情境：服務不支援 `tools` 而回 400，面板顯示「這個服務不支援工具呼叫，請到 AI 設定關閉」，不是原始 JSON
- 情境：供應商是 DeepSeek 且工具開著，同一段對話問第二個問題時，先前的回覆附有 `reasoning_content`，不會回 400；其他供應商的請求不帶這個欄位
- 情境：重新開啟有工具呼叫的舊對話，工具呼叫列照樣顯示；開啟 1.0.2 以前的舊對話不受影響
