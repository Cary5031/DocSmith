# add-ai-token-usage 任務清單

- [ ] 1. `tokens.js`：中英文混合的 token 估算、模型 context 對照表、以實際 usage 校正的係數
- [ ] 2. `aichat.go`：解析串流結尾的 `usage`，以 `ai:usage` 事件送出 prompt / completion / total
- [ ] 3. 面板：用量長條與文字，輸入、勾選文件、切換對話時即時更新
- [ ] 4. 顏色分級（60% 黃、80% 紅）與「建議開新對話」按鈕
- [ ] 5. `ai.go` ＋ AI 設定：「對話長度上限」欄位（每供應商，留空＝自動判斷）
- [ ] 6. 中英文字串與樣式
- [ ] 7. 建置並以本機模擬服務驗收

## 驗收條件

- 情境：面板底部看得到長條與 `已用 / 上限 tokens（百分比）`
- 情境：在輸入框打字，數字跟著變；清空又變回去
- 情境：勾選一份長文件，數字立刻變大；取消勾選又降回來
- 情境：服務有回報 usage 時顯示實際數字（文字沒有「約」）；沒回報時顯示估算值（有「約」）
- 情境：切換到另一組對話，長條跟著那一組的內容變化
- 情境：上限設 8000、內容約 5000 tokens 時長條轉黃；超過 6400 轉紅並出現「建議開新對話」
- 情境：點「建議開新對話」，等同按下「新對話」，長條歸零
- 情境：AI 設定的上限留空時，選 gpt-5.6 類模型會自動帶出對應的 context 大小
