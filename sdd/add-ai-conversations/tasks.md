## 驗收條件

- 情境：按「新對話」，訊息清空，剛才那組出現在「對話紀錄」最上面
- 情境：打開對話紀錄點一組舊的，訊息回到那一組的狀態；再切回來也正確
- 情境：在對話紀錄裡刪掉一組，清單少一筆，目前這組不受影響
- 情境：開啟資料夾 A 時只看得到 A 的對話紀錄；換成資料夾 B 就看到 B 的
- 情境：對話檔存在 `<資料夾>\.DocSmith\chats\` 下，用記事本打開是亂碼；同目錄有內容為 `*` 的 `.gitignore`
- 情境：把 `.DocSmith\chats\` 裡的檔案弄壞或換帳號後開啟，程式自動改讀 `%APPDATA%` 的明文備援，對話仍在
- 情境：按某一組的「匯出」，得到一個 Markdown 檔，裡面是一問一答、程式碼區塊完整
- 情境：按「備份」得到一個 JSON 檔；把對話全部刪光後用「還原」選那個檔，對話都回來了
- 情境：重開程式後，對話紀錄與目前這組對話都還在
- 情境：升級後第一次開啟，原本 `state.json` 裡的對話變成紀錄中的第一組，內容沒有遺失
